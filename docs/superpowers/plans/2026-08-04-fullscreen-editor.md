# Fullscreen Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a distraction-free fullscreen writing surface to the post editor at
`/admin/write` — serif type on a user-chosen mist/amber background, with all
editor commands in a floating pill that collapses to a circle while typing.

**Architecture:** No new route. The existing `<div data-editorjs>` root is
promoted to `fixed inset-0 z-50`, so the Editor.js instance and the surrounding
`<form>` never unmount and autosave keeps working. The init script already binds
tools with `root.querySelectorAll("[data-editorjs-tool]")`, so pill buttons that
carry the same data attributes get wired for free. Alpine holds the UI state.

**Tech Stack:** Hono JSX (not React), Alpine.js 3 (CDN, loaded when
`meta.alpine`), Tailwind CSS v4, Editor.js, `node --test` with `tsx`.

**Design spec:** `docs/superpowers/specs/2026-08-04-fullscreen-editor-design.md`

## Global Constraints

- **Hono JSX, not React.** `jsxImportSource: "hono/jsx"`. Use `class` (never
  `className`) and lowercase handlers (`onclick`). Import `FC` from `hono/jsx`.
- **Keep `.js` extensions on relative imports**, including imports of `.tsx`
  files (`module: "NodeNext"`). E.g. `import { EditorJs } from "./EditorJs.js"`.
- **Strict TypeScript, two-space indent.** Formatter is `deno fmt`
  (`npm run fmt`). There is no linter.
- **Never hand-edit `public/styles.css`** — it is generated by the Tailwind CLI.
  Edit `src/styles.css` and run `npm run build`.
- **Palette is fixed:** light `bg-amber-50 text-mist-600`, dark
  `dark:bg-mist-600 dark:text-amber-50`. Inverse UI mirrors it.
- **`--color-mist-600` must remain exactly `oklch(45% 0.017 213.2)`.** It is used
  sitewide; changing it is a visual regression everywhere.
- **Everything in the pill is `rounded-full`** — the bar, every button, every
  swatch, divider caps, the collapsed circle. No hard corners in this UI.
- **Dark mode is a `dark` class on `documentElement`**, set by the bootstrap
  script in `MainLayout.tsx` from `localStorage.getItem("theme")`. Tailwind's dark
  variant is `@custom-variant dark (&:where(.dark, .dark *))`.
- **Icons are lucide, inlined as SVG.** Existing convention:
  `class={iconClass}` plus `{...commonSvgProps}` (which supplies
  `aria-hidden`, `stroke-linecap="round"`, `stroke-linejoin="round"`,
  `stroke-width={2}`, `viewBox="0 0 24 24"`).
- **Full check before handoff:**
  `npm run typecheck && npm test && npm run build && git diff --check`

- [ ] **Step 3: Write the script**

The pattern matches `postSlugScript` in `Write.tsx`: a template literal exported
as a string, hung on `window`, invoked from Alpine `x-init`.

```ts
export const editorFullscreenScript = `
window.EDITOR_SURFACE_INK = {
  "amber-50": "mist-600",
  "mist-200": "mist-800",
  "mist-400": "mist-900",
  "mist-600": "amber-50",
  "mist-800": "amber-50",
};

window.resolveEditorSurface = (stored, isDark) => {
  const inks = window.EDITOR_SURFACE_INK;
  const fallback = isDark ? "mist-600" : "amber-50";
  const surface = typeof stored === "string" && inks[stored] ? stored : fallback;
  return { ink: inks[surface], surface };
};

window.initEditorFullscreen = (root, state) => {
  if (root.dataset.fullscreenReady === "true") return;
  root.dataset.fullscreenReady = "true";

  const pill = root.querySelector("[data-editor-pill]");
  const enter = root.querySelector("[data-editor-enter]");
  const exit = root.querySelector("[data-editor-exit]");
  const nativeToggle = root.querySelector("[data-editor-native-toggle]");
  const swatches = root.querySelectorAll("[data-editor-swatch]");
  const holder = root.querySelector("[data-editorjs-holder]");

  const isDark = () => document.documentElement.classList.contains("dark");
  const storageKey = () => "editor:surface:" + (isDark() ? "dark" : "light");

  const readStore = (key) => {
    try {
      return window.localStorage.getItem(key);
    } catch {
      return null;
    }
  };

  const writeStore = (key, value) => {
    try {
      window.localStorage.setItem(key, value);
    } catch {
      /* storage disabled — the choice simply does not persist */
    }
  };

  const applySurface = (name) => {
    const resolved = window.resolveEditorSurface(name, isDark());
    state.surface = resolved.surface;
    root.dataset.editorSurface = resolved.surface;
  };

  window.setSurface = (name) => {
    applySurface(name);
    writeStore(storageKey(), state.surface);
  };

  applySurface(readStore(storageKey()));

  let collapseTimer = 0;

  const openPill = () => {
    window.clearTimeout(collapseTimer);
    state.pillOpen = true;
  };

  const scheduleCollapse = () => {
    window.clearTimeout(collapseTimer);
    collapseTimer = window.setTimeout(() => {
      if (!state.fullscreen) return;
      if (pill?.matches(":hover")) return;
      if (pill?.contains(document.activeElement)) return;
      state.pillOpen = false;
    }, 1200);
  };

  holder?.addEventListener("keydown", () => {
    if (state.fullscreen) scheduleCollapse();
  });

  pill?.addEventListener("pointerenter", openPill);
  pill?.addEventListener("focusin", openPill);
  pill?.addEventListener("pointerleave", scheduleCollapse);
  pill?.addEventListener("focusout", scheduleCollapse);

  const requestNative = () => {
    const promise = root.requestFullscreen?.();
    if (promise && typeof promise.catch === "function") {
      promise.catch(() => {
        state.nativeFs = false;
      });
    }
  };

  const setNative = (on) => {
    state.nativeFs = on;
    writeStore("editor:native-fullscreen", on ? "1" : "0");
    if (on) {
      requestNative();
    } else if (document.fullscreenElement) {
      void document.exitFullscreen?.();
    }
  };

  const openFullscreen = () => {
    state.fullscreen = true;
    state.pillOpen = true;
    root.classList.add("editor-fullscreen");
    document.documentElement.classList.add("overflow-hidden");
    applySurface(readStore(storageKey()));
    if (readStore("editor:native-fullscreen") === "1") setNative(true);
  };

  const closeFullscreen = () => {
    state.fullscreen = false;
    window.clearTimeout(collapseTimer);
    root.classList.remove("editor-fullscreen");
    document.documentElement.classList.remove("overflow-hidden");
    if (document.fullscreenElement) void document.exitFullscreen?.();
  };

  enter?.addEventListener("click", openFullscreen);
  exit?.addEventListener("click", closeFullscreen);
  nativeToggle?.addEventListener("click", () => setNative(!state.nativeFs));

  swatches.forEach((swatch) => {
    swatch.addEventListener("click", () => {
      window.setSurface(swatch.dataset.editorSwatch);
    });
  });

  document.addEventListener("fullscreenchange", () => {
    state.nativeFs = Boolean(document.fullscreenElement);
  });

  document.addEventListener("keydown", (event) => {
    if (event.key !== "Escape" || !state.fullscreen) return;
    // Editor.js binds Escape for its own inline toolbars; do not steal those.
    if (event.target.closest?.(".ce-inline-toolbar, .ce-toolbar, .ce-popover")) {
      return;
    }
    if (state.nativeFs) {
      setNative(false);
      return;
    }
    closeFullscreen();
  });
};
`;
```
